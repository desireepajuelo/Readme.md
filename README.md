### Explicación de arquitectura monolítica y microservicios .

- La arquitectura monolítica consiste en un arquitectura en bloque, es decir toda la aplicación es un bloque de código, si hay algún tipo de 
  fallo en una parte del código afecta a todo el bloque.

- A diferencia de la arquitectura monolítica, la arquitectura microservicios consiste en que una aplicación por ejemplo esta formada por  pequeños bloques de códigos por lo que un error en un bloque de código no afecta al resto de código y puede seguir funcionando la aplicación. Esta implantación de los microservicios es difícil al principio pero posteriormente permite la escalabilidad de la aplicación .


### Diferencia entre frontend y backend

La diferencia que hay entre Frontend y Backend es que el Backend es la parte lógica es decir todo aquello que este relacionado con el código y el Frontend es la capa vista es aquello que el cliente ve corresponde al css, javascript y html .
